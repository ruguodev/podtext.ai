## PodText.ai 是什么？

**[PodText](https://podtext.ai)** 是一款 AI 驱动的转录工具，可以把任意**播客、音频或视频转换成干净、可搜索、可导出的文字稿**——只需几秒，无需下载或上传。

粘贴一个来自 **Apple Podcasts、Spotify、小宇宙、YouTube** 或任意公开 RSS/音频链接的地址，PodText 会自动抓取内容，用先进的语音识别 AI 完成转录，并生成一份可以**搜索、总结、导出**的文字稿——支持 SRT/VTT 字幕、纯文本或 Markdown 格式的节目笔记。

你也可以直接上传自己的音频或视频文件（采访、会议、讲座、录音等）。
