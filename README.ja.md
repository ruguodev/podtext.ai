## PodText.ai とは？

**[PodText](https://podtext.ai)** は、あらゆる**ポッドキャスト・音声・動画を、検索可能でエクスポート可能なテキストに変換する**AI搭載ツールです。ダウンロードやアップロードは不要、数秒で完了します。

**Apple Podcasts、Spotify、小宇宙（Xiaoyuzhou）、YouTube**、または公開されているRSS/音声URLを貼り付けるだけで、PodTextがエピソードを取得し、最先端の音声認識AIで文字起こしを行います。得られたテキストは**検索・要約・エクスポート**が可能で、SRT/VTT字幕、プレーンテキスト、Markdown形式のショーノートとして出力できます。

インタビュー、会議、講義などの音声・動画ファイルを直接アップロードすることもできます。

**[無料で試す →](https://podtext.ai)** クレジットカード不要。60分間無料。

## ❓ よくある質問

**PodTextは無料で使えますか？**
はい。新規アカウントには60分間の無料文字起こし枠が付与され、クレジットカードは不要です。

**PodTextはどのプラットフォームに対応していますか？**
Apple Podcasts、Spotify、小宇宙、YouTube、および公開RSSフィードや音声・動画の直接リンクに対応しています。自分のファイルをアップロードすることも可能です。

**YouTube動画の文字起こしはできますか？**
可能です。YouTubeのリンクを貼り付けると、PodTextが完全な文字起こしとSRT/VTT字幕を生成します。

**何言語に対応していますか？**
自動検出により99以上の言語に対応しており、英語・中国語・日本語・韓国語・ドイツ語などが含まれます。

**どの形式でエクスポートできますか？**
SRT、VTT、プレーンテキスト（TXT）、Markdownに対応しています。

**文字起こしだけでなく要約も生成されますか？**
はい。PodTextのAIインサイト機能は、完全な文字起こしに加えて要約・チャプター・要点や引用も自動生成します。
